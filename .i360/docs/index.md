# TechDocs

TechDocs is the docs-like-code solution built directly into Backstage. Engineers write their documentation in Markdown files which live together with their code.

For more information, see the [Progress Infra 360 Developer Portal](https://backstage.infra360.org/catalog/default/component/backstage/docs) docs and the [TechDocs Documentation](https://backstage.io/docs/features/techdocs/).
